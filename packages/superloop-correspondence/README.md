# Correspondence client

`superloop-correspondence poll` and `watch` read the named hosts' correspondence journal. Both require `--known-hosts FILE`, `$HOME/.ssh/known_hosts.clients` provisioned inside the loop entry from verified public node keys, and accept `--ssh-config FILE` and `--state-dir DIR`. The default SSH configuration is the user's `.ssh/config`; the default cursor directory remains `~/dev/superloop-tools/correspondence-watch`. Each opaque `cursor-ALIAS` remains compatible with the former reader. Unknown host keys refuse; SSH cannot enroll or update them. Configured proxy transports remain operator-controlled external dependencies.

Bare reads preserve cursor bytes and metadata, including access time, and create no cursor directory or scratch files. `--advance-cursor` explicitly saves each host's cursor only after its records have been written and flushed. A changed cursor is staged and atomically renamed, then its directory synchronized. A changing invocation holds a per-host descriptor-held `flock` lock; contention refuses rather than overwriting another caller's position. The kernel releases the lock on process death. The stable lock file remains as bookkeeping and must not be unlinked. An existing empty cursor refuses by name; only an absent cursor starts an initial reading. No unrelated cursor is touched. Output success followed by a failed save can replay records on the next call.

Watch calls the polling module directly and publishes every consumed nonempty journal record, including admin records. It returns on user content or transport warnings; it exits 2 at its deadline after printing any admin records it consumed. A bare watch advances only its in-memory position. Existing `CORRESPONDENCE_FEED_DEADLINE_MS`, `CORRESPONDENCE_FEED_POLL_MS`, `CORRESPONDENCE_FEED_POLL_FLOOR_MS` and `CORRESPONDENCE_WATCH_DEADLINE_MS` retain their meanings. Poll duration and verdict lines retain their spelling.

The external tools are `ssh` and `timeout` on PATH; remote reads use `sudo journalctl` and the scanner's existing journal format. Server authentication and exporter bookkeeping are not cursor publication. The package is tier 2 in the correspondence release group; its manifest owns the group's version. Bite 4 ingests and replaces the interim metadata, version-checker and pending-retirement declarations. No former command alias or shim is installed.

A sole `--version` returns one JSON control-plane record on stderr with the installed name and manifest version, no stdout bytes, and exit status zero. The shared release checker verifies this form.

Meson installs the client into the configured binary directory and its identity-bearing build record into the data directory. The predecessor programs and the former client provenance sibling retire through reviewed home-prefix inventories after callers have switched to this client.
