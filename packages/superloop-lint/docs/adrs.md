# The Index Linter Record Register · `reg:indexlinter:adrs`

This register lists the Index Linter decision records included in the public source set. Source-only engineering history is not part of this register.

**Convention (What the tracking table asserts)** · `conv:indexlinter:record-register-tracking`

When public decision records are added, each tracking row names an environment head and the public document that mints it. Every environment in those public records must be registered, and every registered head must exist in its named document.

The public source set currently includes no linter decision records, so this register has no record rows.
