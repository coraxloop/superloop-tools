# Claude Desktop maintenance

`superloop-claude-desktop sync-groups` unions custom groups across account scopes. It preserves first-seen group order and metadata, visits scopes by descending assignment count with stable input-order ties, merges assignments and order, removes dangling assignments and updates the mirror when present. `--migrate` also stages the application's legacy-group migration; only the application later uploads it. `--dry-run` reports counts without a backup or WAL write. The app must be closed. Tables, compressed blocks and fragmented WAL records are decoded in Rust with bounds and checksum validation; malformed storage refuses before mutation. Changing runs back up Local Storage, append a synchronized WAL batch above the observed sequence and verify the resulting records. Already-equal state makes no write.

`merge-sessions` chooses roll-forward successors and then ranks the remaining copies of an entry by `lastActivityAt` and then file modification time, so an archive, unarchive or pin edit that rewrites an entry without advancing its activity still propagates, and a destination whose bytes already equal the winner's is left untouched. `--check` reports equality with status 0 and `CCD_SESSIONS_IN_SYNC`, divergence with status 1 and `CCD_SESSIONS_DIVERGED`, and a refusal with status 2 and `CCD-FAILED`. It writes nothing. Command-line usage errors also exit 2. `--dry-run` previews; a fork still requires `--prefer-successor`. Before its outcome line, a preview or merge prints one line per destination it would change, naming the destination file and its changes among `archived`, `unarchived`, `transcript OLD -> NEW` (the two session identities), `was TIME` and `metadata rewritten TIME`, or `new TIME` for a destination that did not exist. Changing merges require the app closed unless `--allow-live` is explicit, and hold back indexes used by live desktop CLI processes. They tar-back up the indexes and publish changed files atomically, preserving source permissions and times. Transcript files are inspected for existence only and never changed. Apart from those per-destination lines, reports count groups, scopes, sessions, forks and missing transcripts without printing their private values. Every action reports elapsed wall.

The defaults remain Claude's application tree, CLI process registry and projects under the user's home, with process identities from proc. Existing `CCD_LEVELDB_DIR`, `CCD_SESSIONS_ROOT` and `CCD_SESSIONS_REGISTRY` overrides remain. The explicit `--leveldb-dir`, `--sessions-root`, `--sessions-registry`, `--projects-root` and `--proc-root` options cover every inspected root; the application lock is always under the selected LevelDB directory.

`--fixture-root DIR` instead selects `application/Local Storage/leveldb`, `application/claude-code-sessions`, `registry`, `projects` and `proc` beneath DIR. It ignores the inherited desktop path variables and does not consult the user's home or live proc. Explicit root options can still override these fixture defaults. Tests build synthetic application copies and run the built binary; they never copy or inspect personal application state. File and directory reads preserve access times and refuse if that guarantee is unavailable.

The package is tier 2, in independent release group `claude-desktop`, with its own manifest version. Tar is an explicit backup dependency used only by changing commands. Bite 4 ingests and replaces the interim metadata, dependency ledger and pending-retirement inventory. Neither former helper installs as an alias or shim. Symlinked application inputs and malformed storage refuse rather than silently merging an incomplete view.

A sole `--version` returns one JSON control-plane record on stderr with the installed name and manifest version, no stdout bytes, and exit status zero. The shared release checker verifies this form.

Meson installs the client into the configured binary directory and its identity-bearing build record into the data directory. The predecessor programs and the former client provenance sibling retire through reviewed home-prefix inventories after callers have switched to this client.
